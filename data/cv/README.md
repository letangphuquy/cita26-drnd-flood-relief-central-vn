# `data/cv/` — Central Vietnam case study datasets

This directory holds two **different problem instances** for the CV Large
(I=100, H=20, J=12) and CV Small (I=20, H=5, J=2) case studies, generated by
`src/scripts/data_generate_cv.py`.

## `v1/` — canonical dataset (commit `93f5c10`)

Snapshot of `cv_large_drnd.json` / `cv_small_drnd.json` as of commit `93f5c10`
(`master` HEAD at the time this layout was introduced), plus the analysis
artifacts generated against it: `exp2_hub_stability.csv`, `exp2_metrics.csv`,
`figures/`, `maps/`.

**Every existing solver result** (`results/exp2/CV_large_seed0.json`,
`results/exp1/cv_small_pb_nsga.json`, and the ~20 baseline/seed result files)
and **every precomputed flow cache** (`results/exp2/flows/*.json`,
`results/exp1/flows/*.json`) were generated against this version — it is the
dataset behind all current paper figures/results.

Road/water/air accessibility uses a Delaunay-triangulation-based road graph.

## `v2/` — OSRM-validated dataset (commit `fa41c4b`)

Snapshot of the current top-level `cv_large_drnd.json` / `cv_small_drnd.json`
(also copied here for symmetry with `v1/`), plus the OSRM road-graph caches
(`osrm_road_graph_large.json`, `osrm_road_graph_small.json`, also mirrored at
`data/cache/`).

The road network is validated against the OSRM routing API (detour-ratio and
max-distance checks), and the multi-modal accessibility tensors, demand,
supply, risk, hub risk, transport costs, and Theta matrices were all
**recomputed from scratch** — `v2` is a different problem instance from `v1`,
not an incremental patch. Only `global_params` and `nodes` (coordinates/
names/index sets) are unchanged between `v1` and `v2`.

**No solver has been run against `v2` yet** — see
`results/exp2/v2/README.md` and `results/exp1/v2/README.md` for how to add
results once it is solved. Until then, `v2` is explorable in the visualizer's
"Input Dataset" tab only.

## Top-level `cv_large_drnd.json` / `cv_small_drnd.json`

Unchanged, and identical to `v2/`. This remains the default output path for
`data_generate_cv.py` and the default input path for `preprocess_flows.py`
and other scripts — kept at the top level so none of those references needed
to change.
