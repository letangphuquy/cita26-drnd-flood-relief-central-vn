The .txt files come from http://www.optsicom.es/uraphmp/  They include the CAB data and a new USA423 data set 
created for:
	Uncapacitated r-Allocation p-Hub Median Problem
	Peiró J., Corberán A., Martí R. (2013)
	Optsicom project, University of Valencia (Spain)

EACH OF THE INSTANCE FILE IS COMPOSED BY THIS INFORMATION, in order of appearance:

The first number is number of nodes of the instance.
A first matrix of nxn size, regarding the traffics from i to j.
A second matrix of nxn size, regarding the distances from i to j.
